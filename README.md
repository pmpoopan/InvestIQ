# InvestIQ

RAG-based research assistant over Indian mutual fund documents (SIDs, factsheets),
IPO prospectuses (DRHPs), and a SEBI regulation document, with a rigorous
evaluation/ablation study as a core deliverable.

This README is a Phase 0 stub. Full setup, usage, and eval documentation land
in the last phase. See `docs/architecture.md` for the planned design.

## Status

Scaffolding only. No parsing, embedding, retrieval, or generation is implemented yet.
